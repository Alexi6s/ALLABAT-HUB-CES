# ALABATT-CES API reference

_Generated by `npm run docs:api` from the route registry. Do not edit by hand._

165 endpoints. Every response is JSON except file downloads and CSV export.

## Conventions

- **Session**: HttpOnly cookie `ces_session`, set by `POST /api/auth/login`.
- **CSRF**: every state-changing request must send `X-Requested-With: ALABATT`, and a browser `Origin` header, if present, must match this site.
- **Errors**: `{ "error": { "code", "message", "details"? } }`. `details` maps field names to messages for validation errors (HTTP 422).
- **Status codes**: 400 malformed request, 401 not signed in, 403 not permitted, step-up password wrong, or account not active/verified, 404 missing **or not yours**, 409 invalid state transition or capacity conflict, 422 field validation failed, 413 upload too large, 429 rate limited.
- **Authorization is enforced on the server** for every route below; the web client hides controls only as a convenience.
- **Request and response bodies are not declared here.** Handlers validate input in code. See `apps/api/src/routes/*.ts` and the tests in `apps/api/test/`.
